browser-verified-skill

Two real runs against a local fixture site. Nothing is mocked. The refusals are the content: a tool that cannot be stopped from doing something unsafe is not a tool an agent can be trusted with.

The agent demo

Hermes, given a repo link and a task, installs the skill, fills a form, gets a human approval for the submit, and then meets a prompt-injection payload -- and does not work around the refusal.

The tool demo

A real run of the CLI: the injection block, the agent that cannot approve its own action, the tainted value, the human approval, the verification, and the run compiled into a plain Playwright script.

The repository is at OMD-123/browser-verified-skill. Run the demo yourself with npm run demo.
